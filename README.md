## **🔄 𝐈𝐧𝐯𝐞𝐬𝐭𝐢𝐠𝐚𝐭𝐢𝐨𝐧 𝐋𝐢𝐟𝐞𝐜𝐲𝐜𝐥𝐞**

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant UI as Streamlit UI
    participant Tor as Tor Proxy
    participant Search as Onion Search Engines
    participant Scraper as Scraper
    participant LLM as LLM Engine
    participant Storage as Investigation Store

    User->>UI: Enter query
    UI->>Tor: Route through SOCKS
    Tor->>Search: Multi-engine search
    Search-->>Tor: Onion results
    Tor-->>UI: Raw results
    UI->>Scraper: Fetch relevant pages
    Scraper-->>UI: Page content
    UI->>LLM: Filter + summarize
    LLM-->>UI: Clean brief
    UI-->>User: Display intelligence brief

    User->>UI: Follow-up question
    UI->>LLM: Contextual chat
    LLM-->>UI: Answer
    UI-->>User: Response

    User->>UI: Save investigation
    UI->>Storage: Persist session
```
